# Kestrel

常驻菜单栏的 macOS 日常工具，把常用小功能集中在一个轻量的 App 里。

## 功能

- **截图标注**：区域截图、冻结屏幕、标注编辑
- **贴图**：把截图固定在屏幕最上层
- **窗口对齐**：用快捷键把窗口移到半屏、三分之一屏、四分之一屏或其他显示器
- **Finder 右键增强**：拷贝路径、打开终端、新建文件等
- **防休眠**与**清洁模式**
- **系统状态**：在菜单栏查看和控制电池、网络、蓝牙、音量
- **输入法切换**：按 App 自动切换输入法

界面支持简体中文、English、日本語、Tiếng Việt。

## 下载与安装

系统要求：macOS 26 及以上，Apple Silicon。

1. 下载 [Kestrel.zip](https://github.com/leadead/Kestrel-Releases/releases/latest/download/Kestrel.zip)（[所有版本](https://github.com/leadead/Kestrel-Releases/releases)）
2. 解压后把 Kestrel 拖入「应用程序」
3. 打开后按引导授予屏幕录制、辅助功能权限

安装包已通过 Apple 公证。

## 更新

App 会自动检查更新，也可以在菜单栏面板中点「检查更新…」。

## 隐私

Kestrel 不采集、不上传任何数据。
